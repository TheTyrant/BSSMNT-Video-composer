          Keyboard Shortcuts

          Space - Start/Stop Audio (play/pause in track mode)

          F - Toggle Fullscreen

          1–9 - Visualization modes, in menu order · 0 - Clip Auto-Editor

          Ctrl+1 / 2 / 3 - Audio / Assets / Output panel (Alt works too)

          R - Reset All Gains to 1.0

          ? - Show/Hide This Help

          Clip Auto-Editor

          • Track mode: click the timeline to seek. Live mode: the timeline scrolls

          Live Performance Tips

          • Adjust frequency gains for visual balance
